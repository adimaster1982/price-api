# בוט אחזקה לוואטסאפ

בוט שיושב בקבוצת האחזקה בוואטסאפ ומזהה מהודעות חופשיות פתיחה, עדכון וסגירה של קריאות.
הוא שומר הכול במסד נתונים מקומי, שולח סיכום בוקר לקבוצה ומסלים קריאות שנתקעו.

**שני מצבי הפעלה:**
| | מקומי, בלי ענן (ברירת המחדל) | עם Claude |
|---|---|---|
| איפה רץ | טלפון אנדרואיד ישן, או כל מחשב | שרת ענן או כל מחשב |
| זיהוי הודעות | חוקים ומילות מפתח בעברית, על המכשיר | בינה מלאכותית (Claude API, שירות באינטרנט) |
| יוצא החוצה | רק וואטסאפ עצמו | וואטסאפ וטקסט ההודעות ל-Claude |
| הבנת כתיבה חופשית | טובה לניסוחים נפוצים. ניסוח חריג ייפספס | טובה מאוד |
| עלות שוטפת | חבילת סלולר בלבד | שרת ו-Claude |

הבחירה נעשית במשתנה `CLASSIFIER=rules` (ברירת המחדל) או `CLASSIFIER=claude`.

## איך זה עובד בקבוצה
| כותבים בקבוצה | מה קורה |
|---|---|
| "מכונה 7 דולפת שמן, עצרה ייצור" | נפתחת קריאה #12 בדחיפות **דחופה**, והבוט עונה עם המספר |
| Reply להודעת הבוט: "הזמנתי אטם" | הקריאה עוברת ל**ממתינה לחלק** |
| Reply: "אני בדרך" | הקריאה עוברת ל**בטיפול**, והשולח נרשם כאחראי |
| Reply: "תוקן", או "מכונה 7 תוקנה" | הקריאה נסגרת, והבוט מדווח את זמן הטיפול |
| תמונה בלי כיתוב | מצורפת לקריאה האחרונה של השולח (או לזו שעליה ענה ב-Reply) |
| "מה פתוח על מכונה 7?" | הבוט עונה עם הקריאות הפתוחות |
| `!פתוחות` · `!קריאה 12` · `!סגור 12` · `!עזרה` | פקודות מהירות |

**כללי עבודה לצוות** (חשוב במיוחד במצב המקומי):
1. מעדכנים ב-Reply להודעת הבוט או כותבים `#12`.
2. מציינים שם או מספר מכונה ("מכונה 7", "Engel 3", "צ'ילר 2").
3. סוגרים במילה ברורה: "תוקן", "סגור", "עובד".

## התקנה על טלפון אנדרואיד (בלי ענן)

**מה צריך:** טלפון אנדרואיד (גרסה 8 ומעלה, 3GB זיכרון ומעלה), SIM ייעודי עם חבילת גלישה, ומטען שמחובר תמיד.
הכול רץ על הטלפון: הוואטסאפ של המספר הייעודי, הבוט, מסד הנתונים והתמונות.

1. **וואטסאפ:** מתקינים וואטסאפ על ה-SIM הייעודי ומצרפים את המספר לקבוצת האחזקה.
2. **Termux:** מתקינים את Termux מ-**F-Droid** (הגרסה ב-Google Play ישנה ולא עובדת), וגם את Termux:Boot.
3. **התקנה ב-Termux:**
   ```bash
   pkg update && pkg install -y nodejs-lts git
   git clone https://github.com/adimaster1982/price-api && cd price-api/maintenance-bot
   npm install --omit=dev
   cp .env.example .env && nano .env   # DASHBOARD_PASS, PAIRING_PHONE, MANAGER_PHONES
   ./start-android.sh
   ```
4. **חיבור:** הבוט מדפיס **קוד חיבור בן 8 תווים**. בוואטסאפ: מכשירים מקושרים ← קישור מכשיר ← "קישור באמצעות מספר טלפון", ומקלידים את הקוד.
5. **בחירת קבוצה:** פותחים בדפדפן של הטלפון `http://localhost:3000` (משתמש `admin`), ובוחרים את קבוצת האחזקה.
6. **הפעלה אוטומטית:** מגדירים הפעלה אוטומטית אחרי כיבוי והדלקה:
   ```bash
   mkdir -p ~/.termux/boot && printf '#!/data/data/com.termux/files/usr/bin/bash\n~/price-api/maintenance-bot/start-android.sh\n' > ~/.termux/boot/start-bot && chmod +x ~/.termux/boot/start-bot
   ```
7. **סוללה:** בהגדרות אנדרואיד מבטלים "אופטימיזציית סוללה" ל-Termux ולוואטסאפ, אחרת המערכת תסגור אותם ברקע.

**לוח הבקרה** זמין רק על הטלפון עצמו. הניהול היומיומי נעשה מתוך וואטסאפ: פקודות, סיכום בוקר והסלמות.

## התקנה על שרת (מצב Claude או מקומי)
```bash
curl -fsSL https://get.docker.com | sh
git clone <הריפו> && cd price-api/maintenance-bot
cp .env.example .env && nano .env        # מפתח, סיסמה, DOMAIN, CLASSIFIER
docker compose up -d --build
```
- אם אין דומיין, כותבים ב-`DOMAIN` את כתובת ה-IP של השרת בצורה `203.0.113.10.sslip.io`. כך מקבלים HTTPS אוטומטי.
- לחיבור: פותחים את `https://<DOMAIN>`, סורקים את קוד ה-QR מהטלפון של המספר הייעודי ובוחרים קבוצה.

## חשוב לדעת
- **וואטסאפ עצמו הוא שירות ענן של Meta.** אם מדיניות החברה אוסרת כל שירות ענן, גם קבוצת הוואטסאפ הקיימת נמצאת בתחום הזה. הבוט במצב המקומי לא מוסיף יציאה של מידע מעבר למה שכבר עובר בקבוצה.
- **סיכון חסימה:** החיבור הוא לא רשמי (פרוטוקול WhatsApp Web), כך שוואטסאפ עלולה לחסום את המספר. לכן משתמשים רק במספר ייעודי, בקבוצה אחת ובלי ספאם. אם המספר נחסם: SIM חדש וחיבור מחדש, והנתונים נשמרים.
- **גיבוי:** כל הנתונים נמצאים בתיקייה `data/`. בטלפון מומלץ להעתיק אותה מדי שבוע (למשל `cp -r data /sdcard/Download/maint-backup`).
- **הודעות קוליות** נשמרות לקריאה אבל לא מתומללות.

## הגדרות (`.env`)
| משתנה | ברירת מחדל | הסבר |
|---|---|---|
| `CLASSIFIER` | `rules` | `rules` מקומי, `claude` דרך Claude API (דורש `ANTHROPIC_API_KEY`) |
| `PAIRING_PHONE` | — | מספר הבוט (9725XXXXXXXX) לחיבור בקוד במקום QR. חובה כשהבוט רץ על אותו טלפון |
| `DASHBOARD_PASS` | — | סיסמת לוח הבקרה (חובה) |
| `MANAGER_PHONES` | — | מספרים להסלמה, מופרדים בפסיק |
| `URGENT_ESCALATE_HOURS` | 2 | קריאה דחופה שפתוחה יותר מזה תגרום להודעה פרטית למנהל |
| `NORMAL_ESCALATE_HOURS` | 48 | אותו דבר לקריאה רגילה |
| `DAILY_SUMMARY_CRON` | `off` | סיכום בוקר לקבוצה. כבוי בפיילוט. להפעלה: `40 6 * * 0-5` (א'-ו' 06:40) |
| `CLAUDE_MODEL` | `claude-opus-5-5` | מודל הסיווג במצב Claude |

## פיתוח
```bash
npm install
npm test          # בדיקות הלוגיקה והחוקים בעברית, בלי וואטסאפ ובלי Claude
DASHBOARD_PASS=x npm start
```
מבנה: `src/whatsapp.js` (חיבור) · `src/rules-classifier.js` (חוקים מקומיים) · `src/classifier.js` (Claude) ·
`src/agent.js` (לוגיקת הקריאות) · `src/db.js` (SQLite) · `src/scheduler.js` (סיכום והסלמה) · `src/web.js` + `public/index.html` (לוח בקרה).

כדי להוסיף מילים או ציוד שהבוט לא מזהה, עורכים את הרשימות בראש `src/rules-classifier.js`.
