# בוט אחזקה לוואטסאפ

בוט שיושב בקבוצת האחזקה בוואטסאפ, מזהה מהודעות חופשיות פתיחה, עדכון וסגירה של קריאות,
שומר הכול במסד נתונים, ומציג לוח בקרה בדפדפן (גם בנייד). הוא גם שולח סיכום בוקר ומסלים קריאות שנתקעו.

## איך זה עובד
```
קבוצת וואטסאפ ──► בוט (מספר ייעודי, חיבור WhatsApp Web)
                    │  כל הודעה, תמונה או הקלטה
                    ▼
              Claude מסווג: קריאה חדשה / עדכון / שינוי סטטוס / סגירה / שאלה / להתעלם
                    ▼
              SQLite: קריאות, היסטוריה, תמונות
                    ▼
     לוח בקרה (HTTPS) · סיכום בוקר לקבוצה · הסלמה בהודעה פרטית למנהל
```

| בקבוצה | מה קורה |
|---|---|
| "מכונה 7 דולפת שמן, עצרה ייצור" | נפתחת קריאה #12 בדחיפות **דחופה**, והבוט עונה עם המספר |
| Reply להודעת הבוט: "הזמנתי אטם" | הקריאה עוברת ל**ממתינה לחלק** |
| "#12 דני מטפל" | הקריאה עוברת ל**בטיפול**, אחראי: דני |
| Reply: "תוקן" | הקריאה נסגרת, והבוט מדווח את זמן הטיפול |
| תמונה בלי כיתוב | מצורפת לקריאה האחרונה של השולח (או לזו שעליה ענה ב-Reply) |
| "מה פתוח על מכונה 12?" | הבוט עונה לפי רשימת הקריאות הפתוחות |
| `!פתוחות` · `!סגור 12` · `!עזרה` | פקודות מהירות, בלי בינה מלאכותית |

## התקנה (פעם אחת, כשעה)

**מה צריך:**
1. **SIM ייעודי** וטלפון פשוט עם וואטסאפ (רגיל או Business) על המספר הזה. אחרי החיבור הטלפון רק צריך להישאר דלוק ועם סלולר.
2. **מפתח Claude API**: נרשמים ב-console.anthropic.com, טוענים קרדיט ויוצרים מפתח.
3. **שרת ענן קטן** (VPS עם Ubuntu, 1-2GB זיכרון), למשל Hetzner או DigitalOcean, בעלות של 5-7 דולר לחודש.

**על השרת:**
```bash
curl -fsSL https://get.docker.com | sh
git clone <הריפו> && cd price-api/maintenance-bot
cp .env.example .env && nano .env        # ממלאים מפתח, סיסמה ו-DOMAIN
docker compose up -d --build
```
- אם אין דומיין, כותבים ב-`DOMAIN` את כתובת ה-IP של השרת בצורה `203.0.113.10.sslip.io`. כך מקבלים HTTPS אוטומטי בלי לקנות דומיין.

**חיבור לוואטסאפ:**
1. פותחים בנייד את `https://<DOMAIN>` ומתחברים (משתמש `admin` והסיסמה מהקובץ).
2. מופיע קוד QR. בטלפון של המספר הייעודי: וואטסאפ ← מכשירים מקושרים ← קישור מכשיר, וסורקים.
3. מוסיפים את המספר הייעודי לקבוצת האחזקה.
4. בלוח הבקרה בוחרים את הקבוצה מהרשימה. מכאן הבוט פעיל.

## חשוב לדעת
- **סיכון חסימה:** החיבור הוא לא רשמי (פרוטוקול WhatsApp Web), כך שוואטסאפ עלולה לחסום את המספר. לכן משתמשים במספר ייעודי, לא שולחים ספאם, ומשאירים את הבוט בקבוצה אחת. אם המספר נחסם: SIM חדש, סריקה מחדש, והנתונים נשמרים.
- **רשת המפעל לא מעורבת:** השרת בענן, הטלפון של הבוט על סלולר, והעובדים נכנסים ללוח מהנייד. לא מתקינים כלום במפעל.
- **הנתונים** (קריאות, תמונות, פרטי החיבור לוואטסאפ) נמצאים בתיקייה `data/` בשרת. מומלץ גיבוי יומי (snapshot של השרת).
- **עלות Claude:** כל הודעה בקבוצה עוברת סיווג. עם `claude-opus-5-5` זה בערך אגורות בודדות להודעה. אם העלות גבוהה, אפשר לעבור ל-`claude-haiku-5-5` (זול פי עשרות, אבל פחות מדויק בעברית חופשית).
- **הודעות קוליות** נשמרות לקריאה אבל לא מתומללות. תמלול דורש שירות דיבור-לטקסט נוסף.

## הגדרות (`.env`)
| משתנה | ברירת מחדל | הסבר |
|---|---|---|
| `MANAGER_PHONES` | — | מספרים להסלמה, בפורמט 9725XXXXXXXX ומופרדים בפסיק |
| `URGENT_ESCALATE_HOURS` | 2 | קריאה דחופה שפתוחה יותר מזה תגרום להודעה פרטית למנהל |
| `NORMAL_ESCALATE_HOURS` | 48 | אותו דבר לקריאה רגילה (קריאה בדחיפות נמוכה לא מוסלמת) |
| `DAILY_SUMMARY_CRON` | `40 6 * * 0-5` | סיכום בוקר לקבוצה, ימים א'-ו' בשעה 06:40 |
| `CLAUDE_MODEL` | `claude-opus-5-5` | מודל הסיווג |

## פיתוח
```bash
npm install
npm test                                   # בדיקות הלוגיקה, בלי וואטסאפ ובלי Claude
DASHBOARD_PASS=x ANTHROPIC_API_KEY=... npm start
```
מבנה: `src/whatsapp.js` (חיבור) · `src/classifier.js` (Claude) · `src/agent.js` (לוגיקת הקריאות) ·
`src/db.js` (SQLite) · `src/scheduler.js` (סיכום והסלמה) · `src/web.js` + `public/index.html` (לוח בקרה).
